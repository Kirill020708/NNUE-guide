Chess is a symmetrical game, so we can divide the board into two halves. The first half is the first 4 columns (a-d) and the second half is the columns (e-h). If the king is on the second half, we can mirror the position across the `d/e` boundary. Because we need to evaluate both colors, we must calculate `acc_white` based on position, mirrored based on white king (if needed), and the same for `acc_black`. The only problem is that when the king goes from one half to another, we need to recalculate the accumulators from scratch because all of the pieces change their location. But this happens rarely enough to not significantly impact performance. This technique encodes some symmetry of the game into the network, thus improving its quality.
